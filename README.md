# نهان‌مینی (NahanMini) ⚡

یک ورکر سبک، امن و بهینه‌سازی‌شده برای **Cloudflare Workers** جهت برقراری ارتباط VLESS بر بستر WebSocket به‌همراه پنل مدیریت پیشرفته بر پایه دیتابیس **Cloudflare D1**.

## 🌟 ویژگی‌های کلیدی

- **طراحی سبک و بدون کد HTML درون Worker:** به دلایل امنیتی هیچ کد HTML درون کدهای ورکر قرار ندارد؛ تمام صفحات (`login.html` و `dash.html`) به‌طور ریموت از گیت‌هاب با پشتیبان **jsDelivr CDN** لود می‌شوند.
- **طراحی مدرن Neobrutalism:**
  - خطوط مرزی ضخیم، سایه‌های سخت با کنتراست بالا و پالت رنگی جذاب.
  - پشتیبانی کامل از **حالت تاریک (Dark Mode)** و روشن با سوییچ درجا.
  - **طراحی بهینه موبایل:** نوار ناوبری داک در پایین صفحه (Bottom Navbar) روی گوشی‌های هوشمند برای دسترسی آسان.
- **پایگاه‌داده ابری Cloudflare D1:** ذخیره‌سازی همیشگی و لحظه‌ای تنظیمات، نودها و رمز عبور در دیتابیس SQL توزیع‌شده کلودفلر.
- **پشتیبانی از چندین Clean IP و Proxy IP:** امکان وارد کردن نامحدود دامنه‌ها/آی‌پی‌های تمیز و آی‌پی‌های پروکسی برای اتصال TCP.
- **جفت‌سازی و گروه‌بندی نودها (Node Pairing & Categorization):**
  - تخصیص هر Clean IP به یک Proxy IP مشخص جهت عبور ترافیک.
  - دسته‌بندی نودها برای اپراتورهای مختلف (همراه اول، ایرانسل، مخابرات و...).
  - تولید لینک سابسکریپشن خودکار برای **V2Ray/Xray/Sing-box** و پیکربندی گروه‌بندی‌شده **Clash/Mihomo**.
- **اتصال به مخزن پروکسی‌های روزانه (NiREvil ProxyIP-Daily):**
  - جستجو و فیلتر زنده بر اساس کشور، شهر و ISP.
  - **فیلتر هوشمند ضد خطای ۱۱۰۱:** حذف خودکار آی‌پی‌های متعلق به کلودفلر برای جلوگیری از مسدودسازی و ارورهای لوپ در ورکر.
- **امنیت دسترسی و احراز هویت:**
  - محافظت از پنل و API با کوکی و هدر اعتبارسنجی.
  - بنر هشدار فوری در تب لینک‌ها در صورت عدم تغییر رمز پیش‌فرض (`admin123`).
  - قابلیت تغییر مستقیم رمز عبور مدیریت از داخل داشبورد.

## 🚀 راهنمای راه‌اندازی و نصب

### ۱. ساخت پایگاه داده D1 در Cloudflare
1. در پنل کلودفلر به بخش **Workers & Pages** > **D1** بروید.
2. یک دیتابیس جدید با نام دلخواه بسازید (مثلاً `nahan-db`).

---

### ۳. ایجاد ورکر و تنظیم متغیرها
1. یک ورکر جدید در Cloudflare ایجاد کنید و کدهای `worker.js` را در آن ذخیره و مستقر (Deploy) نمایید.
2. در تنظیمات ورکر به تب **Settings** > **Variables and Secrets** بروید:
   - **D1 Database Bindings:** دیتابیس ایجاد شده را با نام متغیر `DB` متصل (Bind) کنید.
   - **Environment Variables:** متغیرهای زیر را بر حسب نیاز تعریف کنید:

| نام متغیر | نوع | مقدار پیش‌فرض | توضیحات |
| :--- | :--- | :--- | :--- |
| `DB` | D1 Binding | - | اتصال به پایگاه‌داده کلودفلر (الزامی) |
| `SUB_PATH` | متغیر متنی | `مسیر-اشتراک` | مسیر محرمانه اشتراک و پنل ورکر |
| `ADMIN_PASSWORD` | Secret | `admin123` | رمز عبور ورود به پنل |
| `LOGIN_URL` | متغیر متنی | آدرس Raw گیت‌هاب | آدرس فایل `login.html` در گیت‌هاب شما |
| `DASH_URL` | متغیر متنی | آدرس Raw گیت‌هاب | آدرس فایل `dash.html` در گیت‌هاب شما |
| `PROXY_IP` | متغیر متنی | `proxyip.cmliussss.net` | آی‌پی‌های پروکسی پیش‌فرض اولیه |
| `CLEAN_IP` | متغیر متنی | `openai.com` | آدرس‌های تمیز پیش‌فرض |
| `FAKE_WEB` | متغیر متنی | - | سایت استتار برای نمایش به درخواست‌های غیرمجاز |

## 📱 ساختار مسیرها (Routes)

پس از استقرار، می‌توانید از مسیرهای زیر استفاده کنید (اگر ورکر را در ریشه باز کنید، خودکار به صفحه لاگین هدایت می‌شوید):

- **صفحه ورود:** `https://your-worker.workers.dev/login` یا `/{SUB_PATH}/login`
- **داشبورد مدیریت:** `https://your-worker.workers.dev/dash` یا `/{SUB_PATH}/dash`
- **لینک سابسکریپشن وی۲ری:** `/{SUB_PATH}/v2ray`
- **لینک سابسکریپشن کلش:** `/{SUB_PATH}/clash`
- **لینک تجمیعی و اطلاعات نودها:** `/{SUB_PATH}/info`
